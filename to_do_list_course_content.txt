## SQL LeetCode-Style Practice

Inside the **SQL course**, add a dedicated **LeetCode-style SQL practice system**.

Do not simply create a separate list of random problems. Each problem must be **matched to the appropriate lesson/module** based on the SQL concept it practices.

For example:

* `SELECT / WHERE` → beginner filtering problems
* `GROUP BY / HAVING` → aggregation problems
* `JOIN` → multi-table problems
* `Subqueries` → nested-query problems
* `CTE` → CTE-based problems
* `Window Functions` → ranking/running-total problems
* `CASE WHEN` → conditional analysis problems
* `Date Functions` → date/time analysis problems

For every relevant SQL lesson, add several progressively difficult problems:

**Easy → Medium → Hard**

Each problem should contain:

* Problem title
* Difficulty
* Business-style problem description
* Database schema
* Table descriptions
* Sample data
* Expected output
* SQL editor/input area
* Test cases
* Correct solution
* Explanation
* Related SQL concept
* Lesson/module relationship
* Student attempts
* Score
* Pass/fail status

Students should be able to open a lesson and see:

**📚 Learn → 🧠 Practice → 💻 Solve SQL Problems**

After completing the lesson, recommend related SQL problems automatically.

Example:

**Lesson: JOIN**

> You learned INNER JOIN, LEFT JOIN and multi-table relationships.

**Recommended Practice:**

1. Easy — Customers and Orders
2. Easy — Employees and Departments
3. Medium — Customers Without Orders
4. Medium — Monthly Sales by Customer
5. Hard — Top Customers by Department

Store every attempt and connect the result to the student's overall course progress.

Important:

* Use a **separate isolated SQL execution environment/database** for student queries.
* Never execute student queries on the production database.
* Restrict dangerous SQL operations.
* Validate both query correctness and expected result.
* Allow students to retry problems.
* Show explanations after submission.
* Track solved/unsolved problems.
* Track Easy/Medium/Hard completion.
* Show recommended problems based on weak topics.

Create the system so additional SQL problems can easily be added later through Django admin.
