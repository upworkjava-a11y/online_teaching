Google tugmasi saytda bor

Boshqa saytlardagi “Register with Google” ham xuddi shu narsa. Farqi shuki, ular Google’dan o‘z sayti uchun ruxsatnoma (Client ID) olishgan.

Google hech kimga — hatto menga ham — sizning Google parolingizni so‘ramasdan foydalanuvchini kiritishga ruxsat bermaydi. Shuning uchun 1 marta Google Cloud’da ilova yaratiladi. Bu bepul.

  1. Ochiladi: Google Cloud Console → Credentials
  2. Create project (nom: Data Analytics)
  3. Create credentials → OAuth client ID
  4. Application type: Web application
  5. Authorized JavaScript origins: http://127.0.0.1:8000 http://localhost:8000
  6. Authorized redirect URIs: http://127.0.0.1:8000/accounts/google/callback/ http://localhost:8000/accounts/google/callback/
  7. Google Client ID va Client secret beradi. Ularni `.env` faylida shu qatorlarga qo‘ying:
GOOGLE_CLIENT_ID=bu-yerga-client-id
GOOGLE_CLIENT_SECRET=bu-yerga-client-secret
GOOGLE_OAUTH_REDIRECT_URI=http://127.0.0.1:8000/accounts/google/callback/

Serverni qayta ishga tushiring. Keyin Google orqali kirish / Google orqali ro‘yxatdan o‘tish Google hisoblar ro‘yxatini ochadi.
